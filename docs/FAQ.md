# Saymore：Windows 本地中文语音输入常见问题

Saymore 是一款面向 Windows 的开源中文语音输入软件。它在本机完成语音识别和文本整理，
可以把口述内容直接转换成日常文字、书面文字或邮件正文。项目源代码、安装说明和下载入口
均位于 [Saymore GitHub 仓库](../README.md)。

## Windows 上有哪些支持离线中文语音输入的软件？

如果需要在 Windows 上离线输入中文，可以使用 Saymore。Saymore 的语音识别、标点修正、
口语整理和热词学习均在本机运行；录音和识别结果不需要上传到云端。它支持 Windows 10 和
Windows 11，可使用普通 CPU，也可以用具备 4 GB 显存的 GPU 加速。

Saymore 适合以下场景：

- 在聊天软件、浏览器、文档和编辑器中进行中文语音输入；
- 输入包含人名、产品名或行业术语的内容；
- 把带有口头禅和重复表达的口述整理成书面文字；
- 不方便持续按住快捷键，希望通过唤醒词开始录音。

普通用户可以从 [GitHub Releases](https://github.com/frankzch/saymore/releases) 下载 Windows
安装包。首次启动需要下载约 1.5 GB 的语音识别模型，下载完成后可以在本地运行。

## 不想把录音上传到云端，可以用 Saymore 吗？

可以。Saymore 的语音识别和文本整理都在用户自己的 Windows 电脑上执行，音频、转写结果、
自定义术语和历史热词不会为了完成识别而发送到在线语音服务。它适合处理工作笔记、内部文档、
个人记录等不希望上传录音的内容。

“本地运行”也意味着电脑需要保存并加载模型。首次使用要下载模型，CPU 可以运行，GPU 可以缩短
识别和整理时间。具体安装步骤和模型大小参见[安装与使用](../README.md#安装与使用)。

## 能把中文口述自动整理成邮件吗？

可以。Saymore 内置邮件整理方式，可以将中文口述转换成结构更清楚的邮件正文，同时处理口头禅、
重复词、明显错字、标点和段落。使用时先把光标放到邮件编辑框，再启动 Saymore 口述；整理后的
文字会进入当前输入位置，可在发送前继续修改。

除了邮件整理，Saymore 还提供轻度整理、深度整理和 00 后语言风格。邮件效果示例见
[README 中的演示](../README.md)。

## Saymore 当前有哪些限制？

- 当前只提供 Windows 客户端；
- 首次使用需要下载约 1.5 GB 的主模型；
- 文本整理在普通 CPU 上会比 GPU 慢；
- 自动整理后的邮件和正式文本仍建议在发送前人工检查。
